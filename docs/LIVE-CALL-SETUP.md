# Live call setup — Orvius

Complete these once. Then place a real test call.

## 1. Add secrets (Cursor environment)

Required:

| Secret | Where to get it |
|--------|-----------------|
| `TWILIO_ACCOUNT_SID` | [Twilio Console](https://console.twilio.com) |
| `TWILIO_AUTH_TOKEN` | Twilio Console |
| `TWILIO_PHONE_NUMBER` | Twilio → Phone Numbers (E.164, e.g. `+15551234567`) |
| `VAPI_API_KEY` | [Vapi Dashboard](https://dashboard.vapi.ai) → API Keys |

Recommended:

| Secret | Purpose |
|--------|---------|
| `VAPI_WEBHOOK_SECRET` | Secures `/api/webhooks/vapi` |
| `ORVIUS_OWNER_PHONE` | Your phone for owner SMS alerts |
| `ENABLE_OWNER_SMS` | Set to `true` |
| `ORVIUS_ADMIN_KEY` | Auto-generated by onboard if missing |

## 2. Sync + onboard

```bash
npm run sync:env
npm run setup:check
npm run onboard
```

Onboard will:

- Verify Twilio + Vapi auth
- Create Summit HVAC business + Vapi assistant if none exist
- Print webhook URLs

## 3. Deploy (required for live webhooks)

Vapi cannot hit `localhost`. Deploy to Vercel and set:

```
NEXT_PUBLIC_APP_URL=https://api.orvius.im
```

Point Namecheap DNS off Manus → Vercel. See `docs/DNS-ORVIUS-IM.md`.

## 4. Vapi dashboard (one time)

1. Open https://dashboard.vapi.ai
2. Attach your Twilio number to the assistant ID from onboard
3. Set server URL: `https://api.orvius.im/api/webhooks/vapi`
4. Set server URL secret to match `VAPI_WEBHOOK_SECRET`

## 5. Twilio SMS (optional)

In Twilio → your number → Messaging:

Webhook: `https://api.orvius.im/api/webhooks/twilio/sms`

## 6. Prove it

1. Call your Twilio number from your cell
2. Complete a qualification (name, service, urgency, address)
3. Check `/dashboard` for call + lead
4. Confirm owner SMS (if `ENABLE_OWNER_SMS=true`)

## 7. Internal test (no phone)

```bash
npm run e2e:dogfood
```

Simulates demo call, Vapi end-of-call, and SMS webhook.
