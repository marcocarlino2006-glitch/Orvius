# Master class — beyond green checkmarks

Passing `bulletproof` / `standard:check` is the floor.
This bar is the craft: honest capture, one owner ritual, Today that acts.

## Ritual (prove → confirm)

1. Dedicated Orvius line exists
2. Owner mobile set (alerts)
3. **Prove** — one real call stamps `lineVerifiedAt`
4. **Confirm** — forward or publish, then stamp `overflowForwardConfirmedAt`
5. No “or I will before go-live” theater — API rejects confirm without prove

## Owner surfaces

| Surface | Master-class rule |
|---------|-------------------|
| Onboarding | Capture teaches steps; prove call; confirm only after verify |
| Settings | One setup hub — not Multi-b cockpit duplication |
| Today Attention | Capture is critical; weekly proof one-tap; failed alerts send test |

## Commands

```bash
npm run master:class           # static honesty + craft gates
npm run bulletproof:product    # product bar (skip cash)
npm run standard:check         # institutional scorecard
npm run multi-b:check          # full multi-b (Stripe/formation still founder)
```
