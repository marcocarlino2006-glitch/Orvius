## The Orvius beyond-moves (category monopoly)

Multi-b discipline is the floor. These five moves are how we go **past** it:

1. **Own the demand moment competitors never see.**  
   ServiceTitan sees jobs after they are booked. Angi sells leads. Orvius holds
   the call that never became a job — taxonomy + ZIP + first-contact stamps on
   every write (`docs/MONOPOLY.md`).

2. **Night-shift category, not AI receptionist.**  
   Fail the brand-swap test. Strip the nav: if the first viewport could belong
   to a generic answering service, we failed (`docs/MASTER-CLASS.md`).

3. **Outcome honesty before outcome pricing.**  
   Pipeline ≠ collected. Estimated ≠ recovered. Charge against completed
   outcomes only after measurement is airtight (`docs/AI-CATEGORY-STUDY.md`).

4. **Prove → confirm → claim — never the reverse.**  
   Line verified before overflow confirm. Wedge 8/8 before outreach volume.
   Named external proof before “case study” language.

5. **Refuse work that does not compound.**  
   No new rings, benchmark dashboards, or marketplace cold-starts until red
   gates close. Schema without shops is not ARR.

## Definition of beyond-ready (one shop, then ten)

**One shop**

- [ ] `npm run beyond:check` passes
- [ ] `npm run wedge:ready` 8/8 on that shop’s real line
- [ ] Owner can say: “I get the lead on my phone before I finish the job”
- [ ] Weekly proof stamped with measured captured-demand bookings
- [ ] Billing entitled OR explicit free pilot — never soft forever

**Ten shops**

- [ ] First paid Checkout closed
- [ ] External named proof (not Summit self-reference)
- [ ] Distribution pipeline has real touches, not seeds
- [ ] Failure log has zero open blockers on the wedge path

Then — and only then — expand OS rings, ads, or outbound volume.
