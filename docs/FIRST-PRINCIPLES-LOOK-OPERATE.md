# First principles — raising Look & Operate

Scores move only when the underlying causes move. Vanity polish does not.

---

## LOOK — what “multi-b look” actually is

A multi-billion presence is not more sections. It is **inevitability**.

| Principle | Question | Orvius move |
|-----------|----------|-------------|
| **P1 · One job** | What is the only thing the first viewport must do? | Brand + one night-shift claim + live line + one CTA pair |
| **P2 · Brand-swap** | Strip the nav — still unmistakably Orvius? | Category + live line artifact, not generic AI SaaS |
| **P3 · One era** | Could a stranger tell we have stacked design systems? | Prefer `ov-` public + `os-` product; stop adding `mkt-`/`inst-`/`cursor` layers |
| **P4 · Restraint** | Does this element earn its pixels? | No stats strips, no Cursor showcase clones, no CTA piles in hero |
| **P5 · Atmosphere** | Is the visual idea the trade at night — or abstract SaaS? | Live-call stage is the artifact; deepen night, don’t decorate |

**What raises Look 65 → ~80 (code):** hero diet, kill first-viewport noise, trades-native nav, brand as hero signal.  
**What raises Look 80 → ~90 (craft):** one CSS era (&lt;8k), real night/bay atmosphere, motion with purpose.  
**What raises Look 90 → multi-b:** density of live shops using it — presence follows proof.

## OPERATE — what “multi-b operate” actually is

A multi-billion operation is not more dashboards. It is **the next truth is unavoidable**.

| Principle | Question | Orvius move |
|-----------|----------|-------------|
| **O1 · One next action** | Does every session know the single red gate? | Mastery next-gate on Command + `/admin/daily` |
| **O2 · Fail closed** | Can money/auth/alerts soft-fail? | Never — 402 / 401 / logged queue |
| **O3 · Ritual &gt; feature** | Would we ship a feature before the daily ritual? | No — wedge, proof, touches first |
| **O4 · Owner language** | Would a shop owner at 6am understand in 5s? | Bay / board / night — not Ring jargon |
| **O5 · Measured honesty** | Are we displaying theater or stamps? | Pipeline ≠ collected; cert before claims |

**What raises Operate 55 → ~70 (code):** next-gate on Command, mastery cockpit, honest empty states.  
**What raises Operate 70 → ~90 (founder):** Stripe $ · Resend · live cert · real outreach · formation · Connect.  
**What raises Operate 90 → multi-b:** 10 proving shops + weekly proof habit + same-day failure culture.
